# OwnFMS.works demo page

The page at https://ownfms-works.github.io/demo/ : a short video of OwnFMS.works, three buttons to try the shared demo, and a link to the free starter.

`index.html` is generated (by `build_demo_page.py` in the main OwnFMS.works project) and contains no scripts. The demo server it links to holds fictional sample data only and is reset every night.
OwnFMS.works is free, open-source software (Apache 2.0), provided as is.
