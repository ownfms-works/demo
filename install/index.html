The same steps in writing

Before you start: use a server just for this, and take a backup (a snapshot from your host is enough). The starter was tested on Corteza 2024.9.1 on Elestio. Other hosts that run that version over https should work, but have not been tried.

  1. Create a Corteza server. On Elestio: choose New service, search for Corteza, pick version 2024.9.1 and the smallest size, name it and press Create Service. When it shows Running, Display Admin UI shows the server's address and the administrator login. Keep them private.
  2. Create a setup key. Open your server's address followed by /admin and sign in. In the System menu choose Auth Clients, then New Auth Client. Name it (for example OwnFMS setup), choose the option for machines (grant type client_credentials), leave the access boxes ticked and press Submit. Copy the client ID and the secret now: the secret is shown only once.
  3. Open the installer at ownfms-works.github.io/installer. Paste your server address, the client ID and the secret, then press Test connection. It only reads, so it is safe.
  4. Install. Keep Load the sample data on for a first install. Tick that the server is just for this and that you understand the software is provided as is. Leave Revoke this setup key when the install finishes ticked and press Install. It takes a couple of minutes, then runs its own checks (you should see no failures) and revokes the setup key.
  5. Look around. Open your server's address followed by /compose/ns/OWNFMS/. The three sample sign-ins (Staff, Manager and Demo Viewer) are optional and each needs a password you choose.
  6. Lock it down. The setup key is already revoked if you left the box ticked (Auth Clients no longer lists it). Then, in your first week: change the administrator password and switch on multi-factor authentication for it (your server's address followed by /auth/security); make a user for each person in Admin > Users with the Staff or Manager role, and give the administrator login to nobody; check that your host's backups are on; and hold off on uploading sensitive documents until Corteza releases the fix for CVE-2026-108729 (a file attached to a record can be downloaded by anyone who has its link). The README's section Your first week has the full list with the reasons.
  7. Keep it current (optional). Automatic reference numbers, due flags, the budget status, the payments check and each grant's History tab are filled in by a small job, run_jobs.py, that runs every few minutes. The README's Keeping it up to date section explains how to schedule it.

The secret you paste into the installer goes only to your own server and is not stored. Use at your own risk; the software is provided as is, with no warranty.
